# Spotyfinder — Machine Learning Song Recommendation ERD

The following ERD models a production-ready data design for implementing a machine learning recommendation pipeline for songs.

```mermaid
erDiagram
    USER {
        uuid user_id PK
        string spotify_user_id UK
        string email
        datetime created_at
        datetime updated_at
    }

    SONG {
        uuid song_id PK
        string spotify_track_id UK
        string title
        uuid primary_artist_id FK
        uuid album_id FK
        date release_date
        int duration_ms
        datetime created_at
        datetime updated_at
    }

    ARTIST {
        uuid artist_id PK
        string spotify_artist_id UK
        string name
        int popularity
        datetime created_at
        datetime updated_at
    }

    ALBUM {
        uuid album_id PK
        string spotify_album_id UK
        string name
        date release_date
        datetime created_at
        datetime updated_at
    }

    SONG_ARTIST {
        uuid song_id FK
        uuid artist_id FK
        string role
        PK "(song_id, artist_id)"
    }

    AUDIO_FEATURE {
        uuid audio_feature_id PK
        uuid song_id FK
        float danceability
        float energy
        int key_signature
        float loudness
        int mode
        float speechiness
        float acousticness
        float instrumentalness
        float liveness
        float valence
        float tempo
        datetime extracted_at
    }

    USER_SONG_INTERACTION {
        uuid interaction_id PK
        uuid user_id FK
        uuid song_id FK
        string interaction_type
        float interaction_value
        datetime interacted_at
        string source
    }

    USER_PLAYLIST {
        uuid playlist_id PK
        uuid user_id FK
        string spotify_playlist_id UK
        string name
        datetime created_at
        datetime updated_at
    }

    PLAYLIST_SONG {
        uuid playlist_id FK
        uuid song_id FK
        int position
        datetime added_at
        PK "(playlist_id, song_id)"
    }

    USER_TASTE_PROFILE {
        uuid profile_id PK
        uuid user_id FK
        json preferred_feature_ranges
        json preferred_genres
        json preferred_artists
        float exploration_rate
        datetime computed_at
    }

    MODEL_VERSION {
        uuid model_version_id PK
        string model_name
        string algorithm_type
        string feature_set_version
        string artifact_uri
        float offline_metric_ndcg
        float offline_metric_map
        datetime trained_at
        string status
    }

    TRAINING_DATASET {
        uuid dataset_id PK
        uuid model_version_id FK
        datetime snapshot_from
        datetime snapshot_to
        int user_count
        int song_count
        int interaction_count
        string storage_uri
        datetime created_at
    }

    USER_EMBEDDING {
        uuid user_embedding_id PK
        uuid user_id FK
        uuid model_version_id FK
        json vector
        datetime generated_at
    }

    SONG_EMBEDDING {
        uuid song_embedding_id PK
        uuid song_id FK
        uuid model_version_id FK
        json vector
        datetime generated_at
    }

    RECOMMENDATION_REQUEST {
        uuid request_id PK
        uuid user_id FK
        uuid model_version_id FK
        string request_context
        datetime requested_at
    }

    RECOMMENDATION_RESULT {
        uuid result_id PK
        uuid request_id FK
        uuid song_id FK
        float rank_score
        int rank_position
        string reason_code
        datetime created_at
    }

    RECOMMENDATION_FEEDBACK {
        uuid feedback_id PK
        uuid result_id FK
        uuid user_id FK
        string feedback_type
        float feedback_value
        datetime feedback_at
    }

    EXPERIMENT {
        uuid experiment_id PK
        string name
        string hypothesis
        datetime start_at
        datetime end_at
        string status
    }

    EXPERIMENT_ASSIGNMENT {
        uuid assignment_id PK
        uuid experiment_id FK
        uuid user_id FK
        string variant
        datetime assigned_at
    }

    USER ||--o{ USER_SONG_INTERACTION : creates
    SONG ||--o{ USER_SONG_INTERACTION : receives

    USER ||--o{ USER_PLAYLIST : owns
    USER_PLAYLIST ||--o{ PLAYLIST_SONG : contains
    SONG ||--o{ PLAYLIST_SONG : appears_in

    SONG ||--|| AUDIO_FEATURE : has

    ARTIST ||--o{ SONG_ARTIST : contributes_to
    SONG ||--o{ SONG_ARTIST : features

    ALBUM ||--o{ SONG : includes

    USER ||--|| USER_TASTE_PROFILE : has

    MODEL_VERSION ||--o{ TRAINING_DATASET : built_from

    USER ||--o{ USER_EMBEDDING : represented_by
    MODEL_VERSION ||--o{ USER_EMBEDDING : generates

    SONG ||--o{ SONG_EMBEDDING : represented_by
    MODEL_VERSION ||--o{ SONG_EMBEDDING : generates

    USER ||--o{ RECOMMENDATION_REQUEST : issues
    MODEL_VERSION ||--o{ RECOMMENDATION_REQUEST : serves
    RECOMMENDATION_REQUEST ||--o{ RECOMMENDATION_RESULT : returns
    SONG ||--o{ RECOMMENDATION_RESULT : recommended_as

    RECOMMENDATION_RESULT ||--o{ RECOMMENDATION_FEEDBACK : evaluated_by
    USER ||--o{ RECOMMENDATION_FEEDBACK : submits

    EXPERIMENT ||--o{ EXPERIMENT_ASSIGNMENT : contains
    USER ||--o{ EXPERIMENT_ASSIGNMENT : assigned_to
```

## Design intent
- **Behavioral signals** are captured in `USER_SONG_INTERACTION` and optionally reinforced through `RECOMMENDATION_FEEDBACK`.
- **Content-based signals** are captured in `AUDIO_FEATURE`, then transformed into `SONG_EMBEDDING`.
- **Personalization state** is represented through `USER_TASTE_PROFILE` and `USER_EMBEDDING`.
- **Model lifecycle traceability** is preserved via `MODEL_VERSION` and `TRAINING_DATASET`.
- **Online serving and ranking auditability** is preserved through `RECOMMENDATION_REQUEST` and `RECOMMENDATION_RESULT`.
- **Experimentation and safe rollout** are supported via `EXPERIMENT` and `EXPERIMENT_ASSIGNMENT`.
