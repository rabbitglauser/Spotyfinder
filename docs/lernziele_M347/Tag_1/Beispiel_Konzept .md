Thema
Gemeinschafts-Geburtstagskarte:   
Eine digitale Geburtstagskarte, an der mehrere Personen gemeinsam mitschreiben können, um einer Person gesammelt zu gratulieren.



Eingesetzte Technologien   
Backend: Node.js/Express · Datenbank: MySQL · Frontend: NGINX/React



MVP

Benutzer kann die Daten für eine Geburtstagskarte (Name des Geburtstagskindes, Nachricht) erfassen. Die Geburtstagskarte wird gespeichert und kann anschliessend wieder angezeigt werden.

Nächste Schritte
- Schritt 1: Mehrere Geburtstagskarten anzeigen (Listenansicht)
- Schritt 2: Upload Foto für Karte
- Schritt 3: Multi-User Support (Benutzerverwaltung)

Externe Services  
MinIO S3 Service für Bild Upload
