Ziel


Die Anwendung wird mit Docker Compose gestartet. Dabei laufen Backend, Frontend und Datenbank in eigenen Containern.


Das Backend verbindet sich mit der Datenbank, liest Testdaten aus einer Tabelle und liefert sie ans Frontend, wo sie auf der Website angezeigt werden.

=> Ihr solltet heute alle mit Docker Container entwickeln können!







Empfohlene Aufteilung:


SQL Datei erstellen

Enthält SQL Code zum Anlegen mindestens einer Tabelle gemäss eurem Konzept.

Inklusive Datensätze: möglichst realistische Daten

Docker-compose.yml erstellen

Backend erweitern um Datenbankanbindung
