Ziel
Ihr erstellt eine Entwurfsversion vom Backend und Frontend und dockerisiert diese.

Empfohlene Aufteilung

Aufgabe 2.1:  
1 Person: Backend lokal zum Laufen bekommen (noch ohne Docker)

1-2 Personen: Docker Image erstellen
Danach Code zusammenführen: euer Backend Code läuft im Container!
Wird von allen Gruppenmitglieder getestet.

Aufgabe 2.2:  
Dasselbe Vorgehen wie bei 2.1 für Frontend.

Aufgabe 2.3:
=> 1 Person
Kann unabhängig von 2.1 und 2.2 erledigt werden.
